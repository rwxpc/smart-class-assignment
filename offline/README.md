# 中小学智能分班管理系统 · 离线版

将在线版（原 PHP 后端）完整逆向移植到本地，**无需联网即可运行全部功能**。前端页面与原网站完全一致（原样保留），后端用 Node.js 重新实现。

## 快速开始

1. 双击 **启动分班系统.bat**（自动打开浏览器访问 http://localhost:8080）
   - 或手动运行：`node server.js`，然后浏览器打开 http://localhost:8080
2. 首次使用：在登录页点击「立即注册」创建账号
   - **第一个注册的账号自动成为管理员**（可进入「用户管理」页面）
3. 按「数据导入 → 参数配置 → 开始分班 → 手动微调 → 导出」流程使用

> 提示：没有 Excel 数据时，可先在「数据导入」页点击「生成 400 条模拟数据」体验完整流程（种子 42 可复现）。

## 分班算法说明（逆向还原）

- 多轮独立运行（默认 10 轮，可调 1~15），每轮：**蛇形初始化 + 2-opt 全局交换优化**，取代价最优解
- 高/低分段保护人数在蛇形阶段硬约束锁定，保证尖子生/后进生各班均匀
- 代价函数：各班各学科 + 总分偏离全校均值的平方和，并纳入性别均衡与 W 分类均衡
- 评判模式「标准版-考虑各分数段极差小（BZB）」：段极差因子指数级惩罚段不均衡方案
- 极差档位（快速/平衡/精细）：控制极差后处理的搜索预算
- 约束：绑定组同班（作为整体移动）、互斥组不同班、预设班级锁定

## 目录结构

```
offline/
├── server.js            # Node.js 后端（HTTP 服务 + 全部 API + 分班引擎入口）
├── 启动分班系统.bat      # 一键启动
├── lib/
│   ├── scheduler.js     # 分班算法（蛇形初始化、2-opt、极差后处理）
│   ├── importer.js      # Excel 导入解析（SheetJS）
│   ├── exporter.js      # Excel 导出生成
│   ├── results.js       # 结果统计、模拟数据、同音名检测
│   └── store.js         # 数据持久化（JSON 文件）
├── public/
│   ├── app.html         # 主应用页面（前端原样保留，仅注入动态数据）
│   ├── login.html       # 登录页
│   └── assets/          # 原网站静态资源
└── data/                # 运行数据（用户、学生、配置、分班结果、留言）
```

## 常见问题

- **端口被占用**：以管理员运行 `set PORT=8081 && node server.js`（或修改启动 bat 中端口）
- **数据备份**：整个 `data/` 文件夹即为全部数据，复制即可备份/迁移
- **忘记密码**：删除 `data/users.json` 后重新注册（数据会清空，请先备份 data/users 目录）
- **性能**：400 人 × 10 轮约 10 秒完成；千人大约 1 分钟内

## 与在线版的差异

- 算法为逆向重写，均衡策略一致但数值结果与原服务器不会逐位相同（原服务器每次运行本身也含随机性）
- 每轮优化在本地全速运行，不受原主机的 IIS 超时限制
- 「极差档位授权」默认对本地用户全开（快速/平衡/精细）
